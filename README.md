# Vidrios Cartagena

Sitio web para una empresa de puertas, ventanas, puertas ventana y divisiones de baño y cocina.

## Estructura
- `index.html`: página de inicio
- `pages/`: páginas internas
- `assets/css`, `assets/js`, `assets/img`, `assets/fonts`

## Paleta
Gris plateado y azul cielo (ver `assets/css/base/variables.css`).
